# Attribution and source availability

This repository distributes a custom build assembled from the SOR3NT Flipper Zero ESP32 port and our Native Tools modifications. It is not an official Flipper Devices release or an original rewrite of every bundled application.

The complete corresponding project/app source used for this release is the explicitly named **T-Embed-Azazil-Flipper-Source-2.0.0-r3.zip** release asset. Original copyright headers, license files and dependency lockfiles are retained. ESP-IDF 5.4.1 and managed components are external build dependencies; consult their licenses as well.

The SD pack starts with the SOR3NT v2.0.0 release resources and replaces/adds the seven custom app builds. Inherited game/demo resources and application licenses remain those of their original authors. A bundled asset is not a claim of ownership by Azazil.
