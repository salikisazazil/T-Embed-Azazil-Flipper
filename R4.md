# r4: deep-sleep repair and Azazil WebStrike

Firmware identity: `2.0.0-azazil-r4`. Target: T-Embed CC1101 Plus, ESP32-S3, 16 MB.

## Deep sleep

- Gate automatic light sleep before teardown so its PM timer cannot be re-armed.
- Clear all inherited wake sources immediately before configuring GPIO0 wake.
- Require GPIO0 high for 200 ms continuously; restart the interval on contact bounce.
- Enable the RTC pull-up and disable the pull-down for the active-low encoder wake key.
- Execute teardown and sleep entry on a dedicated 4096-byte internal-DRAM task stack and internal TCB, independent of the PSRAM FuriThread policy.
- Retain clearing of global deep-sleep GPIO hold state from older firmware.
- Ship mode still falls back to this same deep-sleep path when USB supplies power or BATFET does not disconnect the battery.

Evidence: IDF PM code configures timer wake-up for automatic light sleep; the old shutdown path did not clear it. FuriThread stacks prefer PSRAM. These changes address concrete software risks, but do not establish the cause of every reported wake/reset without device logs.

## WebStrike 1.0.2

One native app at `apps/Tools/azazil_webstrike.fap`, a shared target, sequential Quick Audit, rotary navigation, cancellable worker and SD reports. Fifteen lightweight modules: Nmap, WhatWeb, Nikto, SSLScan, XSS reflection, SQL error indicators, Netcat, headers/cookies, CORS, Gobuster-style paths, HTTP methods, DNS, WordPress hints, ffuf-style query probes and a manual HTTP Basic credential check capped at 20 user-supplied pairs.

These are original bounded implementations, not desktop tool ports. Nuclei, w3af, full Hydra and theHarvester are not included. No database dumping, command execution or browser-based XSS engine. HTTPS uses certificate verification and requires a correct device clock. See `docs/WEBSTRIKE.txt` in the source archive for precise module limits.

## Artifacts and installation

Use the explicitly named complete Source ZIP, merged Plus BIN, and full SD ZIP in the r4 release. GitHub automatic source archives contain only this distribution repository. The SD pack preserves every r3 entry and adds WebStrike (33 FAPs total, 36 ProtoPirate plugins).

Back up settings and SD files. Flash the merged BIN at 0x0 with 16 MB / DIO / 80 MHz; this overwrites the intervening NVS/settings region. Merge SD ZIP contents into the card root. WebStrike needs the r4 firmware's eight new API exports. Prior r3 API entries remain available.

## Validation

Firmware build and partition fit, shutdown host regression test (actual C functions with a mocked HAL), internal-DRAM stack/TCB placement in the linked ELF, WebStrike metadata/relocations and all 98 imports against the linked 1079-entry API table. Previous custom FAPs and plugins are carried over unchanged, not rebuilt for r4. Validation JSON and logs are included in the complete source ZIP.

No physical board was connected. Required device acceptance: repeat deep sleep on battery and USB, hold/release the encoder during shutdown, wait at least 10 minutes without touching it, verify a fresh encoder press wakes it, then repeat after Wi-Fi use and after automatic screen-off. If it restarts, capture the serial reset reason and wake-up cause to distinguish wake from panic/brownout.

## Rebuild

Activate ESP-IDF 5.4.1 and run `bash build_webstrike.sh`. Python dependencies include Pillow and pyelftools. Run `python tests/power/test_shutdown.py` for the host regression test. This release does not claim an ESP32-C6 build or hardware validation.
